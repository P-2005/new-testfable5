01 / THE GAP

ILC is good at repetition. The world is not.

Iterative learning control improves a repeated task by carrying error information from one execution into the next. That same strength becomes a liability when a trial contains a one-off push, slip, missed contact, or sensor anomaly.

The question is not whether quadruped ILC exists. It does. The overlooked implementation question is when to reject a trial before its error becomes persistent feedforward torque.

A

What conventional ILC assumes

Every execution is informative enough to update the phase-indexed memory.

B

What the experiment adds

A confidence layer that uses innovation, contact consistency, and saturation to quarantine corrupted samples.

C

What is deliberately not claimed

This is not a new gait generator, RL policy, or proof of hardware readiness. It is a testable memory-hygiene layer.

02 / THE METHOD

Same plant. Same disturbances. One changed decision.

The ablation isolates the research contribution: both controllers use the same phase-indexed trajectory, feedback PD controller, torque limits, noise, and disturbances. Only the memory update is changed.

STANDARD UPDATEτ[k+1,s] = τ[k,s] + α · (Kp·e[k,s+δ] + Kd·ė[k,s+δ])

How it behaves

The error from every trial is phase-shifted by a small look-ahead and written into the feedforward torque profile. This learns quickly when the disturbance repeats.

Failure mode

A non-repetitive event can create a large update that survives long after the push or slip has ended.

CONFIDENCE-WEIGHTED UPDATEq[k,s] = clip((1 − d[k]) · c[k,s] · (1 − sat[k,s]), 0, 1)τ[k+1,s] = τ[k,s] + α · q[k,s] · Δτ[k,s]

Signals available to the controller

d[k] scores innovation residual and actuator saturation. c[k,s] checks planned versus observed contact at each phase sample.

Safety behavior

When the trial looks corrupted, q approaches zero. The previous memory is retained, while the rejected sample remains available for analysis.

04 / EXPLAINER

See the update decision happen.

A five-scene Manim explanation for a classroom presentation: memory loop, baseline update, corrupted trial, confidence gate, and the testable comparison.

Open transcript

Phase-indexed torque memory. Repeated gait trials share a stored feedforward profile. Baseline ILC adds the tracking error from every trial. A one-off push or slip can therefore contaminate memory. The proposed fix computes a disturbance score and contact consistency, then multiplies the update by a confidence weight. When the trial is corrupted, the weight approaches zero and the previous memory is kept.

BOUNDARIES

What comes next?

The next rigorous step is to port the same update layer to an A1 MuJoCo or Isaac Gym model, replace the toy contact signal with estimated force and base-innovation signals, and sweep disturbance frequency, observation noise, gate threshold, and learning rate.

For the presentation, the honest contribution is clear: selective acceptance of trial data into persistent torque memory.
