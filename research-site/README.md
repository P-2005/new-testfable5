# Disturbance-Gated ILC Lab website

Static research website for the disturbance-gated torque-memory ILC implementation.

## Local preview

```bash
python3 -m http.server 3000 --bind 0.0.0.0 --directory .
```

Then open `http://localhost:3000`.

The site includes the research narrative, algorithm comparison, simulation plot, Manim explanation video, GitHub reproduction link, and accessible responsive navigation.
